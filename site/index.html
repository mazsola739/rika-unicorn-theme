VS Code extension · color + icon theme

Rika Unicorn

Four color themes and a set of hand-drawn file icons for Visual Studio Code. Every color was sampled from one piece of art: a unicorn with a rainbow mane, flowers, a blue butterfly and a “You are sweet.” card.

  • 71icons

The themes

One palette, four moods

Rika Unicorn Dark. The midnight-blue mane. Pink keywords, golden strings, and a cursor the color of the horn.

Rika Unicorn Light. Soft pink, like the unicorn’s blush, with darker code colors that stay easy to read.

Rika Butterfly Sky. Light blue from the butterfly’s wings, with pink and purple accents.

Rika Sweet Teal. The teal of the “You are sweet.” card, with the pink of its lettering.

Code colors

Cute, but still readable

The build measures the WCAG contrast of every syntax color against its editor background. Code stays at 4.5:1 or above and comments at 3:1 or above, in all 4 themes.

Icon theme

Flowers for files, stickers for folders

Each language gets a motif in its usual colors: JavaScript is a yellow flower, TypeScript a blue one, Python a blue-and-yellow butterfly. Folders get a color and a sticker, and a README gets a tiny unicorn.

How it’s built

Generated from code, end to end

  1. Sample

    Pillow quantizes the art into a 23-color palette.

  2. Generate

    One palette file writes 414 workbench colors and 47 syntax rules for each theme.

  3. Draw

    Nine SVG motifs, written as code, become 71 file and folder icons.

  4. Check

    A contrast check flags any code color below the WCAG target.

  5. Package

    A zero-dependency packer zips it all into a .vsix.

Try it

Install

Search for Rika Unicorn in the VS Code Extensions view (Ctrl Shift X), or run:

code --install-extension mazsola739.rika-unicorn-theme
  1. Pick a color theme: Ctrl K then Ctrl T, then Rika Unicorn Dark, Light, Butterfly Sky or Sweet Teal.
  2. Turn on the icons: Ctrl Shift P, then File Icon Theme, then Rika Unicorn Icons.
