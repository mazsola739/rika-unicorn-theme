Four themes

Two light and two dark, all from the same palette. Pick one to preview it.

Midnight blue from the mane, with pink keywords and golden strings.

Soft pink, like the unicorn’s blush. Darker code colors keep it readable.

Light blue from the butterfly’s wings, with pink and purple accents.

How it’s made

Everything is generated from code, so one change to the palette updates every theme, icon and screenshot.

  1. Sample

    Pillow pulls a 23-color palette out of the artwork.

  2. Generate

    One file writes 414 UI colors and 47 syntax rules per theme.

  3. Draw

    Nine SVG motifs become 71 file and folder icons.

  4. Check

    The build flags any code color below the contrast target.

  5. Package

    A small script zips it all into a .vsix.

Install

Search for Rika Unicorn in the Extensions view (Ctrl Shift X), or run this command.

code --install-extension mazsola739.rika-unicorn-theme
  1. Choose a theme: Ctrl K then Ctrl T, and pick Rika Unicorn Dark, Light, Butterfly Sky or Sweet Teal.
  2. Turn on the icons: Ctrl Shift P, then File Icon Theme, then Rika Unicorn Icons.

Prefer a file? Download the .vsix from GitHub.
