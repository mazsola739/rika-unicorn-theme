# Changelog

- New **Rika Butterfly Sky** theme: light blue, like the butterfly's wings
- **Rika Unicorn Light** now has a deeper pink background

- First release: Rika Unicorn Dark, Rika Unicorn Light and Rika Sweet Teal color themes
- Rika Unicorn Icons file icon theme: 12 folder styles (closed + open) and 47 file icons
- Rainbow-mane bracket colors, terminal and git colors, semantic highlighting
